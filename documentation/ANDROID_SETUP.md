## One-time setup
```bash
brew install openjdk@21
sudo ln -sfn "$(brew --prefix)/opt/openjdk@21/libexec/openjdk.jdk" /Library/Java/JavaVirtualMachines/openjdk-21.jdk
echo 'export JAVA_HOME=$(/usr/libexec/java_home -v 21)' >> ~/.zshrc && source ~/.zshrc
brew install --cask flutter android-studio          # or use an existing Flutter checkout
flutter config --jdk-dir "$JAVA_HOME" --android-sdk ~/Library/Android/sdk
flutter doctor --android-licenses && flutter doctor -v
```
Android Studio > Settings > Languages & Frameworks > Android SDK: install the SDK Platform used by Flutter, **Build-Tools**, **Platform-Tools**,
**Command-line Tools (latest)**, and under SDK Tools tick *NDK (Side by side)* version **28.2.13676358** (Show Package Details) or use the script below.

## Install the NDK without a silent stall
```bash
cd ~/Desktop/paywell
bash scripts/install_ndk.sh --accept-licenses --dry-run   # preconditions only
bash scripts/install_ndk.sh --accept-licenses             # real install, visible progress, verified afterwards
```
It checks Java, `sdkmanager`, licences, free disk, `dl.google.com` reachability (printing the exact URL and curl error), refuses to start if an NDK install
is already running or another run holds `/tmp/paywell_install_ndk.lock`, never deletes partial folders, and only prints `VERIFIED` after it reads
`source.properties` (Pkg.Revision) and finds clang. Check manually: `cat ~/Library/Android/sdk/ndk/28.2.13676358/source.properties`.

## Open, sync and run in Android Studio
1. Open the **`mobile`** folder (File > Open). Not `mobile/android`.
2. Settings > Languages & Frameworks > Flutter: Flutter SDK path (`flutter sdk-path` shows it). Install the Flutter and Dart plugins if prompted.
3. Settings > Build > Gradle: Gradle JDK = the JDK 21 (or "JAVA_HOME"). Project Structure > SDK Location should show `~/Library/Android/sdk`.
4. Terminal: `flutter pub get`. Then open `android/` build files and use *File > Sync Project with Gradle Files* if offered.
5. Device Manager: create/start an emulator (an `arm64-v8a` system image on Apple Silicon), or plug in a phone (USB debugging on, authorise the Mac).
6. Pick the **PAYWELL** configuration (shared file `mobile/.idea/runConfigurations/PAYWELL.xml`: entry `lib/main.dart`, `--dart-define=API_BASE_URL=http://10.0.2.2:8080`)
   and the device in the toolbar, press **Run**. If the configuration is missing: Run > Edit Configurations > + > Flutter, Dart entrypoint `lib/main.dart`,
   Additional run args `--dart-define=API_BASE_URL=http://10.0.2.2:8080`, name it PAYWELL. (The XML was hand-written and not loaded in Android Studio by the author.)

## Backend first
```bash
cd ~/Desktop/paywell && cp .env.example .env     # fill the placeholders yourself; never commit .env
```

(debug builds allow cleartext HTTP; release builds must use HTTPS).

## Gradle wrapper and distribution (V2)
* The wrapper is **included**: `mobile/android/gradlew` (executable), `gradlew.bat`, `gradle/wrapper/gradle-wrapper.jar`. Nothing depends on Flutter generating them.
* Distribution: **`gradle-9.5.0-all.zip`**. Reason: your Mac already downloaded `-all` after a long transfer; the wrapper caches by URL, so `-bin` would trigger a second ~130 MB download. `-all` also includes sources/docs that Android Studio uses. If your cache holds `-bin` instead, change the one line in `gradle-wrapper.properties` to `-bin` (nothing else needs to change). Your `~/.gradle` is never touched by these scripts.
* Offline option: `distributionUrl=file\:///Users/<you>/Downloads/gradle-9.5.0-all.zip`. Check it with `bash scripts/android_build_doctor.sh --fetch` (verifies SHA-256, no duplicate download).

## NDK version
`scripts/install_ndk.sh` reads `flutter.ndkVersion` from your Flutter SDK and installs only that; it exits if one is already installed, or if sdkmanager / android-cli / a Gradle or Flutter build is running. `--version X` is refused unless it equals Flutter's value or you add `--allow-mismatch`.

## Android Studio run configuration
`mobile/.idea/runConfigurations/PAYWELL.xml` is a hand-written file in the standard Flutter plugin shape (entry `lib/main.dart`, `--dart-define=API_BASE_URL=http://10.0.2.2:8080`). It is well-formed XML, but **Android Studio import was NOT verified** here. The package ID `com.paywell.app` is set in Gradle (`applicationId`), not in the run configuration; the app's default API URL is already `http://10.0.2.2:8080`. If PAYWELL does not appear in the run drop-down: Run > Edit Configurations > + > Flutter, Name `PAYWELL`, Dart entrypoint `<project>/lib/main.dart`, Additional run args `--dart-define=API_BASE_URL=http://10.0.2.2:8080`, then Apply. Physical phone: use your Mac's LAN IP instead of 10.0.2.2.
